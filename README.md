Projects Overview

### 📚 Book Inventory (`/book-inventory`)
A table-based layout to track reading progress.
* **Uses:** Custom table styling, CSS linear gradients, attribute selectors, and rating dots.

### 📄 Technical Documentation Page (`/documentation-page`)
A documentation layout with smooth navigation.
* **Uses:** `position: fixed` for sidebar navigation, global smooth scrolling, and media queries for mobile viewports.

### 🃏 Playing Cards (`/playing-cards`)
Stylized playing cards built with pure CSS layout techniques.
* **Uses:** CSS Flexbox alignment (`align-self`), scale transforms, and pseudo-classes.
🛠️ Tech Stack & Concepts Covered
HTML5: Semantic elements (<header>, <nav>, <main>, <section>, <footer>), custom data attributes, accessible form controls.

CSS3:

Layout engines: CSS Flexbox & CSS Grid (auto-fit, grid-template-areas).

Positioning: fixed, absolute, relative, sticky.

Responsiveness: Fluid units (rem, vw/vh, %), @media queries.

Visuals & Motion: CSS transform, keyframe animations, transition behaviors, box-shadow, custom CSS variables.
